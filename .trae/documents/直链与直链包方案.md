# 文件直链与直链包 实现方案

> 目标：让用户能生成一条**公开直链**（未登录也能下载/预览），由服务器中转代理取回文件；
> 并把「直链条数」做成可售商品（3 档：50 / 100 / 200 条），与现有高级会员定价合并到**同一个新页面**。
> 本文只做方案，确认后再改代码。

---

## 一、结论：能做，且最难的底层已经现成

现在 `api/file.php` 的下载/预览**已经是服务器中转代理**，不是 302 跳到 Notion：

- 每次请求现调 `NotionClient::downloadUrl($blockId)` 取最新签名地址（[api/file.php L196](file:///c:/Users/17367/Desktop/Notion-drive/notion-drive/api/file.php#L196)）——签名地址会过期，所以不能缓存；
- curl 逐块 `echo + flush` 流式转发，**不落内存、不落磁盘**（[L247-L269](file:///c:/Users/17367/Desktop/Notion-drive/notion-drive/api/file.php#L247-L269)）；
- 透传 `Range`（视频拖动进度、断点续传）、`Accept-Ranges`、`Content-Length`；
- 多副本自动回退、跟随跳转后校验域名可信、收全长度校验、中断告警（[L276-L300](file:///c:/Users/17367/Desktop/Notion-drive/notion-drive/api/file.php#L276-L300)）；
- 预览走白名单 + 安全 Content-Type + `inline` + `nosniff`（[L140-L173](file:///c:/Users/17367/Desktop/Notion-drive/notion-drive/api/file.php#L140-L173)）。

**直链缺的只有两件事**：一个「免登录入口」，加一层「链接签发 / 校验」。所以风险不在能不能做，而在**开放公开访问后的滥用与泄露控制**。

## 四、数据模型

### 4.1 新表 `share_links`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT PK | |
| `token` | VARCHAR(64) UNIQUE | **32 字节 `random_bytes` → 64 位 hex**，不可预测 |
| `user_id` | BIGINT | 生成者（额度归属） |
| `file_id` | BIGINT | 指向 `uploads.id` |
| `expires_at` | DATETIME NULL | NULL = 永久 |
| `download_count` | INT DEFAULT 0 | 需求 3：下载次数 |
| `last_accessed_at` | DATETIME NULL | 需求 3：最后访问时间 |
| `last_ip` | VARCHAR(45) NULL | 审计用（IPv6 也放得下） |
| `revoked_at` | DATETIME NULL | 撤销时间，非空即失效 |
| `created_at` / `updated_at` | DATETIME | |

索引：`token`（唯一）、`file_id`、`(user_id, revoked_at)`（算额度用）。

### 4.2 额度与商品（全部走 config，不新增第二张表）

| config 键 | 含义 | 默认 |
|---|---|---|
| `share_enabled` | **需求 4：全局总开关** | `0`（先关闭，配置好再开） |
| `share_default_days` | 默认有效期天数 | `7` |
| `share_packs` | 3 档套餐 JSON：`[{"count":50,"price":"9.90","enabled":1}, …100…, …200…]` | 预置 3 档，价格留空待管理员填 |
| `users.share_links_quota` | 该用户**已购直链条数**（新列，INT DEFAULT 0） | `0` |

**额度口径**：可用条数 = `share_links_quota`（管理员视为不限）；已用条数 = `COUNT(share_links WHERE user_id=? AND revoked_at IS NULL)`。
过期链接不计入已用（自然释放），撤销也释放——避免"买了 50 条却因过期被永久占用"。

### 4.3 `orders` 扩展（迁移）

- 加列 `product_type VARCHAR(20) NOT NULL DEFAULT 'premium'`（`premium` / `share_pack`）；
- 加列 `product_meta` VARCHAR(255) NULL（直链包存 `{"links":50}`）；
- 迁移照 [Schema.php L146](file:///c:/Users/17367/Desktop/Notion-drive/notion-drive/src/Schema.php#L146) 的版本号方式追加，**存量订单自动落到 `premium`**，不影响历史数据。

## 五、后端改动

### 5.1 抽出共用流式转发

把 `api/file.php` 的 GET 输出主体（L138-L330 那一段：预览判定 → 响应头 → 暂存文件分支 → Notion 副本分支 → 回退与告警）抽成 `src/Files/FileStreamer.php`，暴露一个方法：

```php
FileStreamer::stream(array $file, array $owner, bool $inlineRequested): never;
```

- `api/file.php`（登录态，现有鉴权不变）与直链入口**共用同一份实现**，保证 Range / 预览安全 / 副本回退行为完全一致；
- 抽的是**搬移**，不改逻辑，便于回归比对（改完后两条链路的响应头应逐字节一致）。

### 5.2 直链入口 `s.php`（根目录，短路径便于分享）

- 参数：`t=<token>`，`dl=1` 强制下载（不带则按预览白名单决定 inline / attachment）；
- **校验顺序**（任一不通过都输出一个独立错误页，不泄露文件信息、不回显 token）：
  1. `share_enabled` 为开 → 否则"直链服务未开放"；
  2. token 命中 `share_links` → 否则"链接无效"；
  3. `revoked_at` 为空 → 否则"链接已撤销"；
  4. `expires_at` 为空或未过期 → 否则"链接已过期"；
  5. 对应 `uploads` 记录 `status IN (UPLOAD_VISIBLE_STATUSES)` → 被内容审核隔离（quarantined）、已删除的**一律不出内容**；
  6. `data_lost = 0` → 否则按现有《数据丢失》文案提示；
  7. 生成者若被封禁 → 直链一并失效（与站内封禁口径一致）。
- 通过后：`download_count + 1`、`last_accessed_at = NOW()`、`last_ip` 落库，再交给 `FileStreamer::stream()`；
- **重要**：直链只用 token 鉴权，**不复用登录会话**，也不接受 `id` 参数，避免反推文件。

### 5.3 生成 / 撤销 / 列表 `api/share.php`

- `action=create`：需登录 + CSRF + `share_enabled` 开 + (`isPremiumUser()` 或管理员) + 文件属本人（管理员可任意）+ 额度未用尽 → 返回完整 URL（按站点地址拼 `s.php?t=…`）；
- `action=revoke`：仅生成者本人或管理员，置 `revoked_at`；
- `action=list`：本人的直链（文件名、创建时间、到期时间、下载次数、最后访问时间、撤销按钮）；
- 与站内一致：封禁用户不可生成（走 `userActiveBan()` 拒绝）。

### 5.4 前端（dashboard）

- 文件行操作区增加「直链」（沿用现有行内操作样式）；
- 点击弹窗：有效期选择（1 / 7 / 30 / 永久，默认 7）→ 生成 → 展示链接 + 「复制」按钮；
- 弹窗内列出该文件已有直链（含次数/最后访问/撤销）；
- 侧边栏或上传卡显示「直链额度：已用 X / 共 Y（管理员不限）」；
- 未开通时提示「直链仅对高级用户开放」并给新页面入口。

## 七、安全与风险（必须正视）

1. **链接泄露 = 文件泄露**：这是"公开直链"的固有代价，靠 ①可设有效期 ②随时撤销 ③下载次数审计 三者兜底；方案里不提供"永久 + 不可撤销"的组合以外的额外保护。
2. **中转 = 双倍带宽**（入站 Notion + 出站客户端）。直链是公开的，被大量并发拉取会直接吃服务器带宽；本次只做**记录与告警**（异常高频访问写 `Logger::warning` + 后台告警），**不做限速**——如需限速另开一版（见待确认项 5）。
3. **不新增放行口**：直链只校验 token，不碰会话；`api/file.php` 的鉴权逻辑一行不动。
4. **不泄露存储细节**：响应里绝不出现 Notion 域名、block id、token；错误页只给"链接无效/已过期"。
5. **与风控联动**：内容审核隔离、数据丢失、封禁用户三种状态一律不出内容（见 5.2 校验第 5-7 条）。
6. **配额防刷**：生成直链需高级用户 + 条数上限；管理员不限但记日志。

## 十、验收方式

- 语法与静态：`php -l` 全部改动文件、`node --check assets/app.js`、版本号全站一致性检查；
- 生产**只读**探针（不写库）：token 校验各分支（开关关闭 / 不存在 / 已撤销 / 已过期 / 隔离文件 / 数据丢失）逐一命中预期提示；
- 真实交互：生成直链 → **无痕窗口**（未登录）打开 `s.php?t=…` → 能下载、图片/PDF 能预览、视频能拖进度 → 次数 +1 → 后台撤销或关闭总开关 → 同一链接立即失效；
- 回归：`api/file.php` 登录态下载/预览的响应头与改动前**逐字段一致**（Range、Content-Type、Content-Disposition、Accept-Ranges）。
